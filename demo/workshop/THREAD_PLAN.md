# Quai's algorithm, played out in a thread (Nov 5–8). Drafts for Leo to edit.

Rule for every post: no tokens, no wallets, no "buy". We show the *mechanism*, not the coin.

Quai facts come from the docs: <https://docs.qu.ai/learn/advanced-introduction/soap>.
- Workshares are proof-of-work that misses the block target but still earns, in proportion.
- SOAP routes merge-mined subsidies from other chains to the protocol, which buys back and burns QUAI.

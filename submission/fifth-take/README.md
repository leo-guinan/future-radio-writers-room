# Fifth Take: nodes recruit, comments are workshares

**Video:** [`fifth-take.mp4`](fifth-take.mp4), 1:37. Posted as a reply in the Second Take thread.

## Quai mechanisms, played without crypto

| Quai | In the game |
|---|---|
| **Workshares:** proof-of-work that misses the block target, still paid in proportion ([docs](https://docs.qu.ai/learn/advanced-introduction/soap)) | Each verified comment in the thread is a workshare. Players are paid pro rata, not winner-take-all. |
| **SOAP:** value from other chains routed back into the network | The prize, or the Story.markets debt if we don't win, flows back to the work. |
| **Sharding** | Every node is a neighborhood. Operators earn for players who sign in through their node, with diminishing returns (`sqrt`), so spreading out beats piling up. |

There are no tokens and no wallets. Hayek is a fictional portrayal.

    confidence.

  - every reply to the parent post becomes a game, for the four days of the virality contest;
  - @QuaiNetwork miners run validation nodes, and Leo runs the first, to validate the validators;
  - pledges for projects that should be funded.

  The monitor shows the live workshop page.
- **The close.** "We can make the strangest loop, and engineer generosity." Leonardo: Strangest Loop
  is an artist the show made an episode about ([`../IMPACT.md`](../IMPACT.md)). The call: Quai
  miners, run a node; everyone else, reply.

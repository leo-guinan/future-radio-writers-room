# The Ledger of What Happened

This is a local production release of a Future Radio meeting episode. It is not a YouTube publication and is not canonized by external release.

The episode follows Agnolo, Borges, and Leonardo as they reconcile six public YouTube uploads, five local receipts, two existing repositories, and four smaller productions with no durable repository. The technical concepts are provenance, work/release/asset separation, content-addressed identity, append-only event logs, lineage, uncertainty states, and independent readback.

Production state: audio assembled and locally QA'd.
Publication state: not published.
Repository state: catalog metadata prepared; binary promotion requires repository readback.

The episode deliberately says “probable” for the E01 YouTube linkage because its original upload receipt was not found locally. It does not turn title and runtime agreement into cryptographic proof.
